# css-button-effects
CSS Button Effects
Author

S. Bhanu

Description

This project demonstrates how to create a styled button using HTML and CSS with hover, active, and focus effects.

Features
Button styling
Hover effect
Active/click effect
Focus effect
Smooth CSS transition
Box shadow
Button movement animation
CSS Effects Used
Hover

The :hover pseudo-class changes the button color, moves the button slightly upward, and adds a shadow when the mouse pointer is placed over it.

Active

The :active pseudo-class changes the button appearance while the button is being clicked.

Focus

The :focus pseudo-class adds an outline when the button receives keyboard or mouse focus.

Technologies Used
HTML5
CSS3

How to Run
Download or clone this repository.
Open the index.html file in a web browser.
Move the mouse over the button to see the hover effect.
Click the button to see the active effect.
Use the Tab key to see the focus effect.
